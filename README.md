# Wi-Fi QR Code Generator

Công cụ tạo mã QR Wi-Fi chuẩn quốc tế cho cả iOS (iPhone/iPad) và Android. Quét 1 chạm để kết nối trực tiếp không cần nhập mật khẩu.

## Tính năng
- Hỗ trợ tất cả thiết bị điện thoại có camera (iOS & Android).
- Tùy chọn in thẻ Wi-Fi dán tường hoặc tải ảnh mã QR.
- Hoạt động 100% trên trình duyệt (client-side), an toàn và bảo mật mật khẩu.
